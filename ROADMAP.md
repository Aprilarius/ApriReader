# Roadmap

ApriReader began as a small personal library and grew one practical feature at
a time. The current release already covers the things I wanted from a daily
reader: a dependable local library, comfortable reading, audiobooks, notes,
statistics, and read-aloud without an account.

## Available today

- Local library for EPUB, PDF, FB2, TXT, HTML, Markdown, CBZ, CBR, and DOCX.
- Separate audiobook library with multi-part books, CUE and playlists.
- Reading progress, bookmarks, highlights, notes, quotes, and full-text search.
- Typography, themes, book spreads, PDF and comic reading modes.
- Manual metadata editing and optional Russian or English online lookup.
- Audiobook player with speed, output device, sleep timer, bookmarks, tray
  playback, statistics, and achievements.
- Local Windows read-aloud and optional user-configured cloud voices.
- Local statistics, reading goals, activity calendar, and achievements.
- Explorer file associations, keyboard navigation, Narrator support, high
  scaling, forced colors, backups, and database recovery.

## Next priorities

- Sign Windows releases with a trusted certificate and timestamp.
- Finish clean-system checks on current Windows 10 and Windows 11 builds.
- Prepare store pages and distribution packages without changing the local,
  privacy-first character of the application.
- Keep improving compatibility with real-world book files reported by readers.
- Explore a mobile companion only after the Windows release is settled.

New services will be considered only when their privacy, licensing, reliability,
and long-term cost are clear. The source books must always remain under the
reader's control.

# Security policy

## Supported version

Security fixes target the latest published ApriReader release.

## Reporting a vulnerability

Please use GitHub's private security-advisory reporting for
`Aprilarius/ApriReader`. Do not publish exploitable details, private library
paths, copyrighted books, database contents, credentials, or personal data in
a public issue.

Include the ApriReader version, Windows version, affected format, minimal safe
reproduction steps, and whether the issue can modify files, execute content,
make an implicit request, expose local data, or prevent startup.

ApriReader has no telemetry. Diagnostics are shared only when a user explicitly
chooses to provide them.

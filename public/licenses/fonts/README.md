# Bundled reading fonts

ApriReader bundles the following reading-font families under the SIL Open Font
License 1.1:

- Charis SIL
- IBM Plex Serif
- Literata
- Lora
- Merriweather
- Source Serif 4

The complete license for each family is stored beside this file. The fonts are
used only for local book rendering and never trigger a network request.

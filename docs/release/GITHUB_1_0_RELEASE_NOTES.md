# ApriReader 1.0

ApriReader is a private Windows library and reader for DRM-free books.

## Included

- EPUB, PDF, FB2, TXT, HTML, Markdown, CBZ, CBR, and DOCX.
- Continuous text and two-page book-spread reading.
- Detailed typography, reading profiles, local font import, and bionic
  highlighting.
- Search, bookmarks, highlights, notes, saved quotes, and Markdown export.
- Favorites, authors, series, metadata editing, and explicit Open Library
  lookup.
- Local statistics, daily goals, calendar, and 42 progressive achievements.
- Keyboard, Narrator, high-scaling, and forced-colors support.
- Guarded database backup and recovery.

## Privacy

The GitHub build contains no telemetry, Steamworks, bundled books, language
models, TTS engine, generated covers, or background catalog requests.

## Windows installer

This initial installer is not code-signed, so Windows may identify it as coming
from an unknown publisher. Download only from the official release page and
verify the attached SHA-256 checksum.

Existing RC1 and beta installations can be upgraded in place; local library
data and reading progress remain in the same application profile.

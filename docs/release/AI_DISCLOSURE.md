# Generative AI disclosure

This record is intended for distribution forms that ask about generative AI.
It must be kept consistent with the exact submitted build and store assets.

## Pre-generated content

The original library key art in `docs/steam/assets/source-key-art.png` was
created specifically for ApriReader with the OpenAI image generator. Store and
library capsules are deterministic crops and project-name overlays generated by
`scripts/generate_steam_assets.py`. No AI-generated book, book cover, narration,
sample library, or model is bundled in the application.

The Steam content survey should disclose the project-specific key art as
pre-generated AI artwork. Screenshots must contain only the actual application
and synthetic or public-domain library fixtures.

## Content generated while the application runs

ApriReader provides optional speech synthesis through voices installed in
Windows and optional bring-your-own-key ElevenLabs, Google Cloud
Text-to-Speech, and Azure AI Speech services. For conservative marketplace
disclosure, the three cloud services should be reported as live-generated
speech audio.

- Cloud speech is disabled by default.
- The user explicitly selects one provider, supplies that provider's key, and
  accepts a provider-specific disclosure before text leaves the device.
- Only bounded fragments of user-selected local book text are submitted.
- The feature synthesizes speech from supplied text; it does not prompt a
  language model to create new narrative or factual content.
- Requests use fixed reviewed provider hosts, bounded input and output, and
  validated audio responses. Credentials remain in Windows Credential Manager.
- The user is responsible for the submitted text, provider account, terms,
  quota, billing, and permission to process the material.

ApriReader does not include a general-purpose live image, text, or media
generator and does not silently send user content to an AI service.
